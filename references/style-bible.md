## 动作与幽默

表情可以夸张，人物模型保持自然。每张只有一个容易读懂的主隐喻：

- 复盘账号：拿放大镜查看实体数据表。
- 剪视频：用剪刀剪一条实体胶片，旧电脑上是简化时间线。
- 研究同行：藏在纸箱后，用大望远镜研究账号缩略图。
- 玩AI与聊天：把两台旧显示器当交流对象，屏幕用简单聊天气泡。
- 健身：旧健身角举重量，明确表情和受力，毛巾提示洗漱。
- 听播客：手机、耳机、可读线缆连接和放松姿态，不硬加失败情绪。

固定脸形、眉眼鼻嘴比例、发型发色、眼镜形制、项链、体型、标题和渲染；允许合理时段光线、姿态和活动服装变化。默认原图既是风格参考也是人物身份参考，不另画匿名人物。只有用户明确上传或指定新身份时，身份才由该图决定；通过首图只帮助连续性，不能覆盖原身份图。

## 偏移修正

| 问题 | 修正 |
|---|---|
| 脸过于粗块或像雕塑 | 恢复自然面部结构、正常鼻嘴比例、柔和游戏明暗，去掉显著三角块面。 |
| 头发变尖锐发片 | 恢复蓬松不规则发束与适度细节，保持用户发色和轮廓。 |
| 变实拍 | 保留游戏建模与贴图、适度简化皮肤、不加毛孔和电影景深。 |
| 变精致动画电影 | 降低圆润卡通比例、强皮肤散射与塑料感，恢复普通环境光和旧材质。 |
| 全图黄 | 墙与暗部回到灰绿，只让木桌纸箱及局部灯偏暖。 |
| 人物换脸 | 重复完整身份锚点，带上通过首图和必要身份图。 |
| 海报化或动作混乱 | 恢复小灰框白字；减到一个主动作与主道具，检查接触关系。 |
| 继承头像背景或手机UI | 只保留身份点，去掉插画笔触、城市背景、胶片边框、外层状态栏与播放控件。 |
