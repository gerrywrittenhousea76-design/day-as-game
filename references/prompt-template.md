# 独立图片提示词模板

每张填成完整实际内容，不以「同上」省略人物、画风或标题。

```text
Use case: stylized-concept
Asset type: 一张3:4满幅竖图，单场景
Primary request: 严格保持输入的固定原图画风，只把活动改为「{活动}」的一个清晰实体动作；不要自行重新设计画风或改变面部抽象程度。
Input images: 图1为assets/style-reference.png固定原图，是唯一默认风格基准，不能用重新生成图替代。{逐一标注用户身份图（如有）、本次通过首图（如有）；身份图只决定身份，首图只锁定角色连续性，不覆盖图1的画风。}
Subject: {完整人物锚点、明确回答的性别、正常脸形和五官比例、发色发型、眼镜等识别点、合适衣着。}
Scene/backdrop: {活动场景}，斑驳灰绿墙、旧木铁、纸箱、文件柜与旧工业空间。
Action: {一个主动作}，主道具{一个重点}，{自然可信的接触关系}。
Expression: {具体表情、视线、身体姿态}；夸张表演，但保持正常五官结构。
Style/medium: 与图1保持相同人物渲染、自然五官、柔和面部明暗、哑光皮肤、蓬松发束及头发细节、旧环境贴图和普通直接阴影。不要自行加强写实或抽象效果；不将脸改成粗块雕塑，不将头发改成三角发片。所有风格判断直接对照图1。
Composition/framing: 3:4，单场景中景或中全景，略广角，人物约占45–70%，背景清楚，左上留标题。
Lighting/mood: {时段}，轻微灰绿日光灯顶光，弱反射、暗部有信息，合理窗光或局部暖灯。
Color palette: 低饱和橄榄灰、土褐、旧卡其、暗牛仔蓝，局部一个重点色。
Text (verbatim): 「{最终标题}」
Typography: 只出现此主标题，左上距左约7%、距顶约6–8%，中灰小圆角框，充分内边距，普通白色中文无衬线，细至中等字重，一行。
Constraints: 同一人物、识别点、服装和自然旧游戏质感；手脚正常，接触可信，标题清楚。
Avoid: 极端低模粗块脸、三角发片、几何雕塑、真人摄影、真实皮肤毛孔、精致动画电影、2D插画、像素画、动漫大眼、现代干净办公室、强电影虚化、霓虹HDR、过度金黄、华丽排版、水印、手机外层截图UI、多格拼贴、额外台词或人物。
```

返修示例：「只修正{实际问题}，保留已通过的脸、发型、性别、衣服、姿态、镜头、自然旧游戏材质、灰绿土褐配色和其他区域；标题逐字为『{标题}』，不新增物品。」

## 示例日常

男性创作者，默认原创人物。早起健身、洗澡；白天看账号、做数据、复盘、研究同行；剪视频、玩AI并聊天；晚上用手机听播客。

| 图片 | 标题 | 主动作 |
|---|---|---|
| 封面 | 一个创作者的一天 | 工位开工，少量哑铃、毛巾、图表、胶片与耳机作线索 |
| 01 | 锻炼一些意志力 | 举哑铃，身旁毛巾和洗漱角 |
| 02 | 抢救一些账号数据 | 用放大镜查实体数据表 |
| 03 | 偷学一些同行打法 | 用望远镜研究账号屏幕 |
| 04 | 剪掉一些废片 | 剪刀剪实体胶片 |
| 05 | 和AI聊一些可能 | 对着两个显示器交流 |
| 06 | 听一些噪声之后 | 戴耳机听手机 |

工具或节目名以用户实际输入为准，不默认所有人用同一工具或听同一节目。小标签可写明确需要的名称，避免额外标志和无关文案。
